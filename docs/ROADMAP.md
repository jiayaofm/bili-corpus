## 二、待办（按优先级）

### P0 — 影响结论有效性

- [ ] **正样本不足且分布不均**
  分类正类仅 37 条，其中 36 条集中在科技（16）与娱乐（20）。
  分类器实际学的是「这两个分区的 AI 说话方式」，对其他分区没有验证。
  *需要*：找到 AI 活跃的其他类型视频，补充跨分区正样本。

- [ ] **话题与分区共线**
  每个分区只采了 1 个视频，无法区分「分区效应」与「话题效应」——
  某个簇聚集，是因为它是"游戏区"，还是因为它是"海龟汤"这个话题？
  *需要*：每个分区补到 2–3 个不同话题的视频（当前 6 个 → 约 18 个）。

- [ ] **跨批次标注标准不一致**
  第一批 151 条判定 AI 占 36.4%，第二批 157 条降至 23.6%。
  门槛在收紧，两批数据不能直接合并比较。
  *需要*：统一标注规范后重标，或明确分开报告。

### P1 — 影响方法完整性

- [ ] **风格聚类尚未得到可解释的多类体裁**
  当前只切出「短评 18 字 / 长评 81 字」这样篇幅层面的分层，
  没有得到「玩梗党 / 站队党 / 干货党 / 表情党」这类语义体裁。
  *可能方向*：双通道聚类（风格 + 话题分离后分别建模）、或换用句向量表示。

- [ ] **未计算标注者间一致性**
  全部由一人标注，无法排除个人判断偏差。
  *需要*：至少两人独立标注同一批 50–100 条，计算 Cohen's Kappa。

- [ ] **聚类评估指标单一**
  目前只报 silhouette 与 AMI。可补充 Calinski-Harabasz、Davies-Bouldin，
  以及人工可解释性评分。

## 四、已记录的方法论事故（保留作为经验）

这些不是待办，是**已经踩过并修正**的坑，写在这里避免重蹈：

1. **标签循环**：早期用规则打分器生成 AI 标签，再拿这批标签训练模型、
   在同一批数据上评估，得到 F1 = 1.000 的假结果。
   根因是「特征 → 标签 → 用同一批特征训练」。改用人工盲标后才修正。
2. **抽样偏差**：分层抽样让样本里 AI 占 23.6%（真实 7.9%），
   未加权指标高估召回率近一倍。已引入加权还原。
3. **样本身份带偏**：早期打分器显示账号名与规则分数，
   标注者会被既有判断影响。现改为盲标（隐藏分数、账号名、点赞数）。
4. **账号名是混淆变量**：AI 账号 78% 名字含「鱼/鲸」，
   但真人粉丝也这么起名（提升度只有 4 倍）。已从默认特征中剔除。
