# 去鱼腥味改写：LoRA 实验结果

> 底座 Qwen3-1.7B + LoRA(r=16)，8 GB 显存训练
> 数据：大肥鱼改写真人热评 1020 对，过滤后 319 对
> 结论：**过滤前学成「换标点」，过滤后才真的学会改写**

---

## 一、三次训练，两次失败

| 版本 | 数据 | 数据量 | train_loss | 定性结果 |
|---|---|---:|---:|---|
| fish-b | 未过滤 | 783 | 1.829 | ❌ 只会换标点 |
| fish-a | 未过滤 | 783 | 1.857 | ❌ 只会换标点 |
| **fish-a2** | **过滤** | **319** | 2.229 | ✅ **真的在改写** |

**loss 更高的那个反而是对的。** 这件事本身就说明：指标好看不等于学会了。

---

## 二、第一版的坑：数据里 52% 只改了标点

未过滤版本在 dev 上跑出：

```
内容保留 0.845（真人目标 0.800）
鱼腥味   0.256（真人目标 0.254）
骨架重复 0.5%
```

**每一项都「达到甚至超过真人」——但它其实什么都没改写。**

把样本拉出来对照才发现：

```
输入  女生的嗓子太好了，真的爱了。
模型  女生的嗓子太好了 真的爱了          ← 只是把句号换成了空格
真人  救命那个女生的嗓音太好了吧 真的爱了

输入  为简介三连。希望每个人都明白。
模型  为简介三连，希望每个人都明白        ← 只是换标点
```

回头查数据，最像的几对长这样：

```
原  龙族对虫族的压制
改  龙族对虫族的压制。          ← 「改写」就是加个句号
```

全量统计（去标点后的字符 bigram Jaccard）：

```
相似度 ≥0.5   508 对（52%）
相似度 ≥0.7   241 对（24%）
相似度 ≥0.8   154 对（16%）
```

**一半样本在教模型「加句号」。** 模型当然学这个——那是 loss 最低的路径。

---

## 三、过滤

在 `tools/build_rewrite_pairs.py` 里加了五道闸：

| 剔除条件 | 数量 |
|---|---:|
| 相似度 ≥0.5（基本只动标点） | 407 |
| 原文不是中文（多半是翻译） | 127 |
| 原文太短（<8 字，学不到东西） | 39 |
| 改写等于原文（没改） | 34 |
| 原文是链接（不是评论） | 15 |
| 长度比极端 | 1 |
| **可用** | **397（39%）** |

过滤后：鱼腔中位 **41 字** → 真人中位 **55 字**。真改写确实在扩写。

---

## 四、过滤后的结果

训练：319 条 / 5 epoch / 100 步 / train_loss 2.229
评测：78 条 dev，按视频留出，全部未参与训练

### 鱼腥味（检测器，越低越不像大肥鱼）

```
改造前（输入）        0.446
模型输出              0.401     中位 0.405
真人目标（下限）      0.397
基线·强（每条加表情）  0.359     ← 比真人还低
基线·匹配（26% 加表情）0.393
```

走完理想距离的 92%。**但「只换标点加表情」的基线走完了 108%——
说明这个指标本身可以被标点欺骗，不能单独当成功依据。**

### 内容保留

```
模型输出  0.705     真人目标 0.594
丢失过半  9/78（12%）
```

**高于真人目标。** 含义有两面：没有为了改风格而丢信息（好），
但人类改写时本来就只保留六成左右的具体信息，模型保留得更多说明它改得还不够松。

### P(AI)

```
模型输出  0.356     真人目标 0.368
判成 AI   22/78（28%）
```

没有掉回「通用 AI 腔」。

### 形态

```
模型  中位 40 字  <10字 4%  表情 22%  骨架重复 0.0%
真人  中位 48 字  <10字 0%  表情 22%  骨架重复 0.0%
```

表情率精确对上（22% / 22%），骨架重复为 0。
**但长度仍偏短 8 个字**——模型没学到真人那种啰嗦劲。

### 定性对照

```
鱼  点歪不点歪都是说法。现在是材料学卡住了…
模  你点歪点歪都是说法嘛，现在是材料学卡死了…      ← 加主语「你」、加语气词「嘛」
人  哪有什么点歪不点歪的，就是目前材料学到瓶颈了…

鱼  地球还能住，所以没人造飞船。哪天住不了了，航天立马起飞。
模  地球还住人，所以没人造飞船，那什么时候住不了，航天马上就会起飞
人  因为地球还能住，地球哪天住不了了，那离地科技肯定飞速发展[笑哭]
```

**加主语、加语气词、判断句改反问、句号改流水句。** 这是真的风格迁移。

---

## 五、关于「鱼腥味检测器」的诚实结论

这个指标**目前不能作为主证据**，原因有二：

1. **带标点时它可以被作弊。** 只把句号换成逗号、加个表情，
   分数就能低于真人目标。AUC 0.956 里有 19% 是标点贡献的。
2. **剥掉标点后它又没有量程。** 去标点后 AUC 降到 0.707（说明选词层面
   确实还有真信号），但分数对输入/输出/真人全是 0.279，量不出改善。

所以本实验的判据是**多指标 + 人工读样本**，不是单一分数。

---

## 六、下一步

1. **让大肥鱼补一轮数据**：要求改写时明显改动措辞（相似度 <0.5），
   并把「原文是链接/外语/太短」的直接跳过——现在 61% 被剔除，浪费了采集时间
2. **长度**：模型输出比真人短 8 字，可以在数据里加权更长的目标
3. **检测器**：改成词级 + 语料库校准，或者用嵌入距离，摆脱标点依赖
4. **人工评测**：抽 30 条让人盲判「哪条是真人写的」，这是唯一可信的上限

## 七、复现

```bash
# 造数据（带过滤）
python -X utf8 tools/build_rewrite_pairs.py

# 训练
python -X utf8 tools/train_lora.py --data data/rewrite/a_train.jsonl \
  --out D:\dsh-ai\lora\out\fish-a2 --max-len 320 --bs 2 --grad-accum 8 --epochs 5

# 评测（生成并保存预测）
python -X utf8 tools/eval_rewrite.py --adapter D:\dsh-ai\lora\out\fish-a2 \
  --data data/rewrite/a_dev.jsonl --save-preds state/preds/fish-a2.jsonl

# 只用保存的预测重算指标（不占 GPU）
python -X utf8 tools/eval_rewrite.py --predictions state/preds/fish-a2.jsonl \
  --triggers data/rewrite/a_train.jsonl
```
