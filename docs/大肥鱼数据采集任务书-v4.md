# 任务书 v4：改写任务的规格修正

> 2026-11-22 · 替代 v3 的「第 5 步」和「六点五、配比」两节，其余照旧
>
> **为什么改**：v3 教的是「压缩」，我们要的是「换说法」。这两个不是一回事，
> 而且前者的产物没法拿来训改写模型。

---

## 一、v3 错在哪

v3 第 5 步写的是：

```
不许把原话改得更长（长度控制在原文的 50%~130%）
举例  原文「有点没活硬整盒饭概念了，后面100与1000与盒饭的关系是？」
      改写「后面那两个也算盒饭吗，纯粹是拿盒饭当标题」
```

后果是一整批数据的形态变成这样：

| | 字数 | 特征 |
|---|---:|---|
| 真人原话（y） | 中位 55 | 啰嗦、有细节 |
| 你的改写（x） | 中位 41 | 短、概括 |

模型从中学到的规律是「**把短话变长**」。可是上线使用时，输入往往是本来就
不短的真人评论，模型无事可做，只能改几个字——**表现就是"点了没反应"**。

实测：78 条测试样本里，49% 的改写幅度落在「只是小改」这一档。

## 二、v4 要什么

一句话：**只换说法，不换信息量，不换长度。**

### 硬要求

```
① 长度   改写后字数 = 原文的 80% ~ 120%
② 信息   原文里每个具体信息都要在：数字、价格、名字、时间、地点、对比对象
③ 立场   原文觉得不好，改写不能变成觉得好
④ 不许   压缩、概括、合并同类项、省略细节、加原文没有的事实
```

### 自查（必须做，两分钟能做完）

每条改写完，对着原文数三样东西：

```
第一步  数长度
        原文 60 字 → 改写必须在 48~72 字之间
        短于 48 就是压缩了，重写

第二步  数数字和英文
        原文有「11 块」「111」「TCL」这种，改写里必须一个不少
        少一个就重写

第三步  看有多像
        把原文和改写都念一遍，问：「这是同一句话换了个说法，
        还是把内容砍掉了一部分？」
        如果你发现自己把两件事并成一件，或者省掉了某个细节 → 重写
```

### 反面例子（v3 那种，现在不要）

```
原文  有点没活硬整盒饭概念了，后面100与1000与盒饭的关系是？
✗ 错  后面那两个也算盒饭吗，纯粹是拿盒饭当标题
       ↑ 压掉了「100 与 1000」，字数从 24 掉到 16，这是压缩
✓ 对  后面那两个也能叫盒饭吗，100 的和 1000 的跟盒饭到底什么关系
       ↑ 信息全在，字数差不多，只是换了说法
```

```
原文  这期视频除了第1个是正经盒饭，后面两个跟盒饭有什么关系？
✗ 错  除了第一个，后面两个跟盒饭没关系吧
       ↑ 少了「这期视频」，语气也被削弱成反问，信息有损耗
✓ 对  这期就第一个是正经盒饭吧，后面那俩跟盒饭有啥关系啊
       ↑ 保留了「第 1 个 / 后面两个 / 盒饭」全部信息
```

## 三、数量

```
每视频   任务二改写 20~30 条（v3 是 12~20）
每视频   你自己的评论 3~5 条（不变）
50 视频  →  1000~1500 条改写

为什么提高  上一轮 50 个视频只产出 319 条可用数据（有效率 39%）。
            提高单视频产量，比多跑视频更省事。
```

## 四、我会怎么筛（提前告诉你，别白干）

你交上来之后，脚本会逐条检查，**不合格的会被丢掉**：

| 检查项 | 阈值 | 上一轮淘汰了多少 |
|---|---|---:|
| 长度的相对比例 | 0.8~1.2 | 少量 |
| 字符 bigram 重合度 | **< 0.55** | **52%（最大杀手）** |
| 原文是不是中文 | 中文占比 ≥70% | 12% |
| 原文长度 | ≥8 字 | 11% |
| 有没有链接 | 有链接的直接跳过 | 15 条 |

**52% 被淘汰，全是因为「只改了几个字」。** 这是 v4 里自查第三步要解决的问题。

## 五、哪些原文不要选（省得白改）

```
✗  带链接的（https:// 或 BV 号）——没法改写
✗  整条都是外语或拼音的
✗  不到 8 个字的短评（"好耶""前排"）——没有信息可换
✗  纯表情 / 纯符号
✗  只是在 @ 人、没有实际内容的
✓  有具体内容的：吐槽、评价、讲经历、抬杠、提问
```

## 六、其余照旧

v3 的以下部分不变，继续照做：

- 第 1~4 步（扒素材、写概要、写自己的评论、拉热评）
- 第 6 步（追加 JSONL 格式）
- 逛哪些视频
- 交付方式

## 附：为什么这版值得重做

上一轮 50 个视频、1020 对改写，最后只有 319 对能用。不是量不够，
是**形态不对**——大部分是"原文加个句号"或"压缩成一句话"。

模型现在的毛病是：

```
训练损失 4.82 → 1.93，最后 2.5 轮不动了   ← 已经学饱了
但 49% 的输出只是小改                    ← 学到的规律不对
```

**给它更多同样糙的数据不会变好，只会更稳地学到错误规律。**
所以必须先修规格，再堆数量。
