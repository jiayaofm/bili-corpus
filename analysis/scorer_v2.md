# 打分器 v2：从「检测器」改造成「裁判」

> 现状快照 · 2026-11-16 · 对应 `pipeline/scorer.py`

## 为什么要改

原来的 `audit.py` 只回答一个问题：**这条是不是 AI**。当检测器够用，但当项目转向
「去除 AI 味」之后，它要当**奖励函数**，这时有三个毛病：

| 毛病 | 表现 |
|---|---|
| 离散、有尖峰 | 命中 +16 / 没命中 +0，没有梯度信号 |
| 容易被作弊 | 只改标点就能从 25 分降到 8 分（实测） |
| 分不出两件事 | 「没有 AI 标记」≠「像人」 |

第三条最致命。实测：一条只把句号换成逗号的改写，规则分 8.0（低于阈值 18，
检测器放行），但离真人平均分（-8.6）还差 16.6 分。

## 改造后的结构

用**两种完全不同的表示**分别算「奖励」和「验收」：

```
reward    = 0.5 × (1 - 规则分归一) + 0.5 × (1 - 随机森林 P(AI))
            看标点、句式、结构统计 —— 可以优化

heldout   = TF-IDF 字 2-4 gram + 逻辑回归 P(AI)
            看**用词** —— 只用于验收，不参与优化
```

两种表示关心的东西不同：改标点能骗到随机森林（它看的正是标点统计），骗不到
TF-IDF（它看的是用了哪些字词）。

**判定规则**

```
奖励涨了 ≥ 0.05，验收没涨到 0.08  →  gaming，打回重写
奖励涨了且验收也涨 ≥ 0.08        →  ok
其余                             →  no-gain
```

## 留出设计的两次试错

这一节值得留在文档里，因为它说明「留出特征」不是随便挑几个就行。

**第一版**：留出 `逗号数 / 分句数 / 短分句占比 / 用字丰富度 / 语气词密度 / 提问密度`

结果作弊案例 **4/4 全部放行**。原因：前四项全是标点驱动的，
把「——」换成「，」就能让它们同时"变人"，留出特征跟着奖励一起涨。

**第二版**：只留 `语气词密度 / 提问密度`

作弊抓住了，但**太窄**——真实改写只要没加语气词就被误判，
5 条真实改写里 3 条被错判为 gaming。

**第三版（采用）**：改用 TF-IDF 判别器，完全换一种表示

分离度实测：

| 改写类型 | 验收改善 |
|---|---|
| 作弊（只改标点） | +0.040 ~ +0.045 |
| 真实改写（换词） | +0.154 ~ +0.185 |

阈值 0.08 落在两组之间，分离干净。

## 验证结果

### 构造用例（9 例）

| 用例 | 奖励变化 | 验收变化 | 判定 |
|---|---|---|---|
| 作弊：破折号换逗号 | +0.342 | +0.040 | gaming ✓ |
| 作弊：全部改逗号 | +0.383 | +0.044 | gaming ✓ |
| 作弊：硬断成短句 | +0.338 | +0.045 | gaming ✓ |
| 作弊：不做任何改动 | +0.000 | +0.000 | no-gain ✓ |
| 真改写：口语化 | +0.424 | +0.154 | ok ✓ |
| 真改写：加语气词 | +0.532 | +0.185 | ok ✓ |
| 真改写：换词改写 | +0.546 | +0.162 | ok ✓ |

**判定正确 7/7。**

### 真实改写集（5 条 × 3 条件）

| 条件 | ok | gaming |
|---|---|---|
| A 只给负面规则 | 1 | **4** |
| B 给真人范例仿写 | **5** | 0 |
| C 规则 + 自查选优 | **5** | 0 |

只给规则的改写，**5 条里 4 条被识别为钻空子** —— 它们确实只是把表面特征抹掉了。
这和人工观察一致：规则改出来的文字「分数降了，但读起来还是 AI」。

## 新特征的实际效果

加之前测了 8 个候选「人味」特征，只有 2 个有区分度：

| 特征 | AI 次/条 | 真人 次/条 | 倍数 |
|---|---|---|---|
| 提问求教 | 0.05 | 0.20 | 4.0× |
| 语气词 | 0.13 | 0.29 | 2.2× |
| 第一人称 | 0.41 | 0.39 | 1.0× |
| 重复字符 | 0.08 | 0.07 | 1.1× |
| 颜文字 | 0.03 | 0.06 | 2.0×（样本太小） |
| 口语词 | 0.25 | 0.12 | 0.5×（AI 反而更多） |
| 自嘲 | 0.03 | 0.01 | 0.3× |
| 不规范标点 | 0.00 | 0.03 | — |

**只有前两个值得加。** 「口语词」反向是因为正则把 `猛/顶/香` 收进去了，
而这些词在 AI 评论里也出现（`94 分是猛`）——这是误伤，不是真信号。

## 已知局限

1. **特征层面有天花板**。「像不像人」不是一组可枚举特征，
   这解释了为什么加特征对 F1 几乎无影响（±0.01）。
2. **验收器本身也会过时**。如果后续用 TF-IDF 参与优化，它也会被作弊，
   届时需要第三种表示。
3. **训练数据只有 263 条、63 个正类**，且集中在娱乐和科技两区。
4. **没有保真检查**。「更像人」和「意思没变」是两件事，后者还没做。
