# 打分器 v4：报表上 AP 0.90 其实是假的

## 一、先质疑那个数字

原报告说 scorer v3「5 折 CV：AP=0.901 / AUC=0.960」。但检查标注来源：

    63 条 AI 正样本来自 3 个视频
    263 条标注总共来自 6 个视频

StratifiedKFold(shuffle=True) 会把同一个视频的评论同时放进训练和测试。
模型可以靠「这条在聊老唐/材料学」认出视频，而不是认出 AI 腔。

按视频分组重测（留一视频交叉验证）：

    随机 5 折    AP=0.903  AUC=0.961   ← 报表数字
    留一视频     AP=0.627  AUC=0.850   ← 真实泛化
    虚高         AP +0.276  AUC +0.110

## 二、更糟的发现：它基本只学会了「长 = AI」

    只用「字数」一个特征     AUC=0.799
    全部 2090 维特征        AUC=0.850
    → 长度单独解释了 94%

同长度区间内 AUC 掉到 0.65~0.86。AI 样本中位 43 字、真人 20 字，
差了一倍多，模型直接抄了近道。

这正是扩展给正常真人长评打 90%+ 的原因。实测把 v3 打分拉出来看：
「&#34;下饭&#34;的本质是把&#34;菜&#34;降级成&#34;米饭的辅助工具」这条真人评论，
v3 给 89.7%。

## 三、换模型没用，是数据的问题

在留一视频标准下扫了九个模型：

    拼接 + LogReg C=0.03    AP 0.627  AUC 0.850   ← 最好
    句向量 + LogReg C=0.03   AP 0.606  AUC 0.847
    手工 + LogReg C=0.3      AP 0.596  AUC 0.830
    随机森林                 AP 0.519  AUC 0.750
    梯度提升                 AP 0.342  AUC 0.600

全挤在 0.53~0.63。**再调模型没有意义。**

## 四、数据从哪来：鲸鱼数据

鲸鱼数据里同一个人的评论横跨 46 个视频：

    whale_20261121.jsonl    自己 221 条 / 真人 1020 条 / 50 视频
    whale_v4_20261122.jsonl 自己 159 条 / 真人 1954 条 / 46 视频

合并人工标注后：1751 条样本（正 443）、66 个视频（53 个含正样本）。

## 五、v4 的成绩

    留一视频        AP=0.915  AUC=0.958
    只用字数        AUC=0.577        ← v3 是 0.799，v4 不靠长度
    同长度区间内    AUC=0.81~0.98    ← 稳得住

端到端（走 HTTP 接口）：

    确认真人 40 条   判红 2（5%）  判黄 15  判绿 23
    大肥鱼 40 条     判红 40（100%）

对照 v3：大肥鱼只抓到 25%（漏了四分之三）。

## 六、阈值改用百分位

概率尺度在换模型后变了：大肥鱼一条评论概率只有 0.60，分位却是 94.7。
按老的概率阈值 0.80 判会被评成 medium，等于漏报。

改成百分位（「比多少比例的真人更像 AI」），在 40 条确认真人上实测：

    阈值 80 分位 → 误判 28%
    阈值 90 分位 → 误判  5%
    阈值 95 分位 → 误判  0%

取 90/70。

## 七、必须说清的限制

这 63 条人工标注的正样本来自 40 多个账号，但都是**同一个人的小号**
（鲸汣本汣、冒泡的鲨鱼的大肥鱼、喵八大肥鱼…）。所以：

**这个打分器识别的是「这一个人设」，不是「任意 AI」。**

遇到别的 AI 写手，它未必有效。要泛化需要别的 AI 来源的标注。
另外语料只有 7 个视频，样本多样性本身有限。
