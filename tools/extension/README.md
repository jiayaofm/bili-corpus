# B站评论 AI 味检测 · Edge 扩展

打开任意 B站 视频，评论区每条评论前面会多两个小徽标：

```
AI 90%   鱼 53%      ←  通用 AI 腔 90%，鱼腥味 53%
```

鱼腥味不低的评论后面会多一个「改成人话」按钮，点一下由本地 1.7B 模型改写，
结果单独显示在下方，**原文不动**。

---

## 两个分数分别是什么

| 徽标 | 测什么 | 来源 |
|---|---|---|
| **AI xx%** | 通用 AI 腔：长句、书面语、复述标题、最后升华 | `pipeline/scorer.py`，40 个手工特征 |
| **鱼 xx%** | 鱼腥味：鱼尚在（大肥鱼）个人的句式习惯 | 986 对改写样本现训的检测器 |

这两个是**不同层次**的问题。一条评论可能「AI 味低但鱼腥味高」——
那正是人设号最难识别的形态。

### 分档

```
AI    低 <25%   中 25~50%   高 ≥50%
鱼    低 <47%   中 47~52%   高 ≥52%
```

鱼腥味的分档来自实测分布：鱼腔样本中位 0.558，真人 0.464，中间是空档。

**⚠️ 必须知道的一件事**：鱼腥味分数可以被「把句号换成逗号 + 加个表情」骗到，
实测这样能拿到比真人还低的分数。**它只做参考，不是判决。**

## 安装

### 1. 启动本地服务

```bash
cd E:\DSH\bili-corpus

# 只打分（不占显存，秒起）
D:\dsh-ai\lora\venv\Scripts\python.exe -X utf8 tools\comment_server.py

# 打分 + 改写（要加载 1.7B，约 40 秒，占 3.8G 显存）
D:\dsh-ai\lora\venv\Scripts\python.exe -X utf8 tools\comment_server.py --lora
```

看到 `[lora] 就绪` 和 `监听 http://127.0.0.1:8849` 就成了。
**必须用 GPU 那个 venv**（`D:\dsh-ai\lora\venv`），项目自己的 `.venv` 里没有 torch。

### 2. 加载扩展

1. Edge 地址栏输入 `edge://extensions`
2. 打开左下角「开发人员模式」
3. 点「加载解压缩的扩展」
4. 选目录：`E:\DSH\bili-corpus\tools\extension`

### 3. 打开一个 B站 视频

右上角会出现一个小条：

```
评论 AI 味   已标 23 条，其中高 AI 味 6 条   [隐藏]
```

点「隐藏」可以收起所有徽标；点扩展图标也能切换。

## 已知问题（都是真的，不是设想）

1. **B站 改版会让选择器失效。** 评论区用了 Web Component + Shadow DOM，
   脚本已经做了穿透和多个候选选择器，但不保证永远有效。失效的表现是
   「已标 0 条」，不会报错刷屏。

2. **改写质量有限。** 底座是 Qwen3-1.7B，会出废话，偶尔还会把意思说反
   （实测「被地球人打懵」→「地球人打的他都不知道」）。用于演示和筛选，
   不要直接当真。

3. **改写慢。** 每条 2~5 秒，所以做成按钮，不做自动全改。

4. **只能本地用。** 依赖 127.0.0.1 的服务，上不了商店，也没必要上。

5. **不改页面原文。** 改写结果放在独立块里，原有评论一个字不动。

## 扩展现在挂的四个信号

| 徽标 | 依据 | 可靠性 | 说明 |
|---|---|---|---|
| **AI xx%** | 手工特征 + Qwen3 句向量 | 中 | 阈值 0.50 黄 / 0.80 红；全库真人误伤约 5.7% |
| **鱼 xx** | 大肥鱼 vs 真人 986 对改写训的检测器 | 中 | 显示的是「比多少比例的真人更重」的百分位 |
| **名含鱼** | 账号名里有没有「鱼/鲸/本鱼」 | **只看名字，没看内容** | 不是判断，是提示 |
| **同款 (ˉ▽￣～)** | 同一账号多条评论带同一串非中文片段 | 高 | 人不固定颜文字，人设号会 |
| **刷屏 ×N** | 同一账号在本页发了 N 条（N≥3） | 高 | AI 评论号最典型的形态 |

后两个不依赖「写得像不像人」，而依赖「一个人不会这样发评论」——
在措辞分不清的时候，它们比分类器可靠。

## 抓取时剥掉「回复 @某人:」前缀

实测同一句话：

`
回复 @我是蓝色大肥鱼: 插个队，顺便我来帮你写     带前缀 94.0%
插个队，顺便我来帮你写                        剥掉后 23.7%
`

差 70 个点。@、冒号、用户名都会进特征，而训练数据里一条前缀都没有。
