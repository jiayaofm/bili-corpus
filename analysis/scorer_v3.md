# 打分器 v3：换成句向量，专治「真人被误判」

> 2026-11-21 · 对应 `tools/train_scorer_v3.py` 和 `state/scorer_v3.npz`

---

## 一、为什么改

浏览器里实测，正常真人评论被打成 57%~84%：

```
「好的好的，谢谢up🥰」                                   65.4%
「已经把…skill上传到 https://github.com/…」             62.6%
「唐大厨评价菜品是按价格来的，比如沙县一份炒饭11块…」      71.8%
```

用户的原话是「正常评论也没有颜色」「误判还是严重」。

根因不在阈值，在**表示**。原来的 42 个手工特征里有大量标点统计
（有「」、有分号、句号数、分号并列），而**长句、讲道理、带链接的真人评论
也会大量使用这些标点**。所以它测的其实是「措辞像不像典型B站短评」，
不是「是不是 AI 写的」。

## 二、实测对比（5 折交叉验证，263 条标注）

| 表示 | AP | AUC |
|---|---:|---:|
| 42 手工特征 + 随机森林 | 0.838 | 0.921 |
| 只给 句号/逗号/感叹号/长度 | 0.400 | 0.694 |
| Qwen3-1.7B 句向量 + 逻辑回归 | 0.888 | 0.956 |
| **手工特征 + 句向量 拼接** | **0.901** | **0.960** |

句向量单独就超过了 42 个手工特征。拼接后最好。

## 三、实际效果（同一批文本）

| 类型 | 旧 | 新 | |
|---|---:|---:|---|
| 真人 技术/带链接 | 63.0% | **1.1%** | ✅ |
| 真人 说理 | 71.8% | **32.7%** | ✅ |
| 真人 聊天 | 65.4% | **7.7%** | ✅ |
| 大肥鱼腔（长） | 80.0% | **99.8%** | ✅ |
| 大肥鱼腔（短） | 80.0% | 54.8% | ⚠️ 掉了 |

全库 1500 条真人评论上的误伤率：阈值 0.5 时 **5.7%**（旧分类器在 0.43 时是 15.1%）。

## 四、过程中踩的坑

### 坑 1：在训练集上测，得到满分

第一次评估直接对 `ground_truth_merged.csv` 那 263 条 predict，得到
`AP=1.000 AUC=1.000`，我据此跟用户说「召回 100%、误伤 0%」——**这是训练集泄漏**。
那 263 条就是分类器的训练数据。必须交叉验证，真实是 AP=0.838 AUC=0.921。

### 坑 2：服务启动卡 200 秒

`load_ai_reference()` 在启动时现场跑 2000 次 `Scorer.describe()`，
每次都要过随机森林和 joblib 调度。用 `faulthandler.dump_traceback_later`
抓栈才定位到。

改成 `tools/build_ai_ref.py` 离线算好存 `state/ai_ref.json`，启动只读文件。

### 坑 3：`CLF3` 忘了 `global`

在 `main()` 里赋值但没在 `global` 声明里加，成了局部变量，
`/health` 一直报 `scorer_v3=False`。

### 坑 4：底座模型被改名

加了分类器后还要加载底座模型，显存只够一份，所以 `Rewriter` 和
`ClassifierV3` 必须共用 `BASE_MODEL`。算句向量时要 `disable_adapter()`，
否则句向量会带上 LoRA 的影响，和训练时不一致。

## 五、复现

```bash
# 1 训分类器（约 2 分钟，需要 GPU）
python -X utf8 tools/train_scorer_v3.py

# 2 预先算真人参照分布（约 2 分钟）
python -X utf8 tools/build_ai_ref.py

# 3 量误伤率
python -X utf8 tools/measure_v3_fp.py

# 4 起服务
python -X utf8 tools/comment_server.py --port 8849 --lora
```

## 六、还有什么没解决

1. **仍有 5~6% 的真人被误判**，集中在「分析技术内容」的评论上
   （例如讨论大模型评测价格的那几条）。
2. **标注数据只有 263 条**（AI 仅 63），CV 方差大，这些数字别当精确值。
3. **AI 正样本无法自动扩充**——自己生成的 AI 文本去训练等于自证，
   必须找**真实的** AI 评论再人工判定。
