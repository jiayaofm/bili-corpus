# 实验 v7：让模型写评论，和真人比

> 2026-11-17 · 两次提示词迭代 · 7 个视频 × 20 条

## 一、为什么换任务

之前做的是「改写」：给一段 AI 评论，改成不像 AI 的样子。

换了。理由是改写这条路有个绕不过去的坎：

```
改写需要   (AI 原文 → 人写的改写) 配对   → 本项目一条都没有
生成需要   (视频标题 → 真人评论)        → 手上有 1035 条
```

而且生成的任务形态和评估形态**天然一致**——训练时「给标题写评论」，
评估时「给标题写评论，看写得像不像」，没有错位。

**改写那条线的成果没有白费**：十条改写规则（补主语、调因果顺序、砍评价句）
是在那个过程里总结出来的，现在成了生成的先验知识。

## 二、怎么评

不比「哪条写得更像人」（那要靠人一条条看），比**分布**：

| 指标 | 为什么选它 |
|---|---|
| 中位字数 | 最直接的形态差异 |
| 10 字以下占比 | 真人常说一句就走，模型倾向写完整论述 |
| 80 字以上占比 | 真人不时写长段 |
| 表情率 | B站的强特征 |
| 骨架重复率 | 生成的多条之间是不是同一个开头换词 |
| P(AI) | 用项目自己的分类器判（注意口径，见下） |

**骨架重复率**用的是每条评论前 5 个可见字符（去掉表情和标点）。
真人短评的骨架重复率是 **2.5%**（640 条短评里 624 种骨架），
拿它当基准线。

注意 v1 的骨架重复率是 **0.0%**——因为它几乎不写短评（10 字以下 0%），
样本里只有 3 条短评，这个数字没有意义。**指标只看短评，所以要配合「短评条数」一起读。**

## 三、结果

### 3.1 两个提示词版本的总体对比

真人侧数字有两种口径，前四列用**全池合并**（1053 条一起算，即「随机抽一条评论看到的样子」）。
按视频等权的口径另见 §3.3。

| 指标 | 真人（全池） | v1（描述性提示） | v2（强制分布提示） |
|---|---|---|---|
| 中位字数 | 23.0 | 58.0 | **19.0** |
| 平均字数 | 41.8 | 62.8 | 19.9 |
| 10 字以下 | 14.8% | 0.0% | 2.1% |
| 80 字以上 | 11.3% | 22.8% | **0.0%** |
| 表情率 | 36.1% | 11.0% | **97.9%** |
| 骨架重复率（短评） | **2.5%** | 0.0% | **20.0%** |
| P(AI) | — | 0.45 | 0.31 |

### 3.2 两种完全不同的失败

**v1：长度全错，但内容有花样**

```
上次也是弹幕刷屏说稳赚，他眼睛都不眨就冲了，结果第二天连本金都没了，
这回又来哈哈哈哈，我怀疑他是专门来给弹幕送乐子的
```

58 字，真人中位 23。中位字数 61.6，一条 10 字以下的都没有。
但每条讲的事情不一样，没有套话。

**v2：长度压对了，内容塌缩成固定套话**

给 v2 的提示词里写明了「真人评论 14.8% 在 10 字以下、绝大多数很短」，
它照做了——中位从 61.6 掉到 19.6。代价是：

```
笑死，弹幕是真的坏 [doge]
弹幕是真的坏啊，骗得人家白高兴一场😂
弹幕是真的坏 骗得鱼哥白高兴一场[笑哭]
弹幕这些人真会忽悠哈哈哈 [doge]
```

135 条短评里骨架只有 108 种，重复率 **20%**（真人 2%）。
最集中的骨架：「94分是真」×11、「这天气预报」×4。

**表情率也爆到 97.9%**——提示词写的是「大约三分之一的评论带表情」，
模型理解成「这条应该带表情」。真人 36.1%。

## 四、核心发现：提示词控制不了分布

这是本实验最重要的一条。

每次生成都是**独立调用**。你告诉它「三分之一带表情」「偶尔写一大段」，
它没法知道这是第几条、前面几条带没带过——于是：

- 「三分之一带表情」→ 每条都带（97.9%）
- 「偶尔写一大段」→ 一条都不写（80 字以上 0%）

**分布是「跨样本」的属性，而提示词只能控制「单条」。** 这不是提示词写得不好，
是这条路的天花板。

由此可以推出：**要让它写出和真人同分布的 1000 条评论，只能靠模型先验来承载，
也就是要训练。** 这给 LoRA 一个明确的、可量化的目标。

## 五、已知局限

1. **P(AI) 这列不能当独立判据**：1053 条真人评论里有 263 条参与过分类器训练，
   这部分会偏乐观。而且 v2 的 P(AI) 是 0.31，比真人的 0.37 还低——
   这不是「比真人更像人」，是**分类器不适用**：它在偏样本上训练，
   判不出「短而随意」这种形态。
2. **只有 7 个视频**，话题极窄。模型可能只学到了这 7 个视频的口音。
3. **20 条/视频样本量小**，骨架重复率这类指标波动大。
4. **没有人工判读**：所有结论都基于分布，没有回答「这几条写得像不像人」。
5. **v1/v2 的差异里混着随机性**：temperature 1.25，单次运行，
   没有重复采样估计方差。

## 六、下一步

分布压不进去 → 上 SFT，让它从数据里学分布。

数据已扩到 **2069 条**（原 866，从 `sub_replies` 二级回复补入，
剔除两个已知 AI 号）。训练形态和评估形态一致。

判据不是「写得像不像」一条，而是三条同时满足：

```
中位字数接近真人
骨架重复率 ≤ 5%（真人 2%）
长度分布两端都有（10 字以下和 80 字以上都要有）
```

**只对上长度但重复率 20%+，等于学到了分布、没学到多样性，仍是失败。**
