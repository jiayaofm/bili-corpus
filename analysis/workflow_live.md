# 接上真模型之后：workflow 跑通了

> 2026-11-16 · 5 条样本实跑

## 结论

**5/5 全部收敛。** 之前「#4 结构性无解」的判断被推翻了——问题不在文本，在于重写策略错了。

## 最关键的认知转变（用户指出）

> 你这是改写评论，你的改写始终是按照这个 ai 框架和 ai 内容改的，你再怎么改词都是一股子 ai 味道，
> 因为正常人根本不会这么说话，也不会这样去表述他们看到的内容。

之前我一直在做「保真改写」：信息一条不丢，只换说法。**这等于把 AI 的内容编排整个保留下来。**

同一句话，两种策略的实测差距：

| 策略 | 验收改善 |
|---|---|
| 保住全部信息，只换说法 | +0.028 |
| 像真人那样只挑一两点说 | **+0.322 ~ +0.479** |

**十倍的差距。** 「选择性」本身就是人味，而保真约束把选择性判成了作弊。

据此改了 `pipeline/rewrite.py` 的硬约束：

```
旧：不许增删原文的信息点，人、事、数字、结论都要留着
新：不许编造；核心立场必须一致；但允许取舍——只挑最扎心的一两点说
```

## 三道关

单靠「AI 味」一关会被钻空子。实测：第一版跑出来的改写把数字删了 67~75%，
把「订阅剩 37%」写成「订阅剩那点」——验收分降了，但这是别扭的中文，不是人话。

现在三关齐备：

| 关卡 | 查什么 | 谁来做 |
|---|---|---|
| AI 味 | 验收分降幅 ≥ 0.08 | 打分器（规则 + TF-IDF） |
| 保真 | 不许新增事实、不许歪曲 | 规则查新增 + LLM 查语义 |
| 自然度 | 像不像随手打的人话 | LLM |

补上自然度之后，同样的输入，模型的写法明显变了：

```
补之前  分数是猛，但订阅剩那点…                ← 被自然度判掉
补之后  分数是挺猛，不过这订阅剩得也太少了…      ← 通过
```

```

#4 改写  字幕看的。阿江那结论我认，分只高小几分，时间六倍，几道ERP题跑一趟就烧掉不少钱，
         只能停。日常开发还是Opus 5.5划算。
```

## 必须承认的代价

改写在**丢掉具体数值**：`#1` 三个数字保留一个，`#4` 八个保留两个（六倍这类量级留下了）。

我一开始把这当缺陷，但顺着上面的认知，**这是手法本身的一部分**——真人不会把评测数据全背一遍。

风险在于：这是不是又一个「指标的口子」？我做了自然度判断来兜底，但那也是 LLM，
可能偏松。**最终验收还得靠人看。**

## 成本与耗时

5 条共 220 秒，平均 44 秒一条。每条调用 LLM 约 6~12 次（生成 ×3 + 语义 ×3 + 自然度 ×3 等）。
`deepseek-v4.1-flash` 单价低，实测单条成本在 0.01 元量级。
